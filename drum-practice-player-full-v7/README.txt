鼓譜練習器 使用說明
====================

【這是什麼】
一個網頁：左邊是歌曲清單，右上是 YouTube 影片，下面是你用 Guitar Pro 做的鼓譜。
按播放時，譜上的游標會跟著影片走。點譜可以跳到那個位置，拖曳可以選取小節反覆練習。

【一、先在自己的電腦上試】
1. 打開這個資料夾，在資料夾空白處開啟「終端機」（Windows 可輸入 cmd；Mac 用 Terminal）。
2. 輸入：  python3 -m http.server 8000
   （沒有 Python 的話改用：npx serve）
3. 瀏覽器打開 http://localhost:8000
4. 左邊「快速試用」：選你的 GP 檔、貼上 YouTube 網址，按「載入」就能看到效果。
   ※ 不能直接雙擊 index.html，一定要用上面的方式開。

【二、加入正式的歌曲】
1. 把 GP 檔放進 songs 資料夾，例如 songs/amazing-grace.gp
2. 用記事本打開 songs.json，照範例多加一段（每首歌之間要有逗號）：
   {
     "id": "amazing-grace",          ← 網址用的代號，英文數字即可，不能重複
     "title": "Amazing Grace",       ← 顯示在清單的名稱
     "artist": "（可不填）",
     "tags": ["敬拜", "慢板"],       ← （可不填）搜尋用
     "gp": "songs/amazing-grace.gp",
     "yt": "https://youtu.be/影片網址",
     "offset": 0                     ← 影片裡「第一拍」在第幾秒；一開始就是第一拍就填 0
   }

【三、放到網路上給學生用（免費）】
1. 打開 https://app.netlify.com/drop
2. 把整個資料夾拖進去，就會得到一個網址。
3. 之後更新歌曲，再拖一次即可。
每首歌有自己的連結：網址最後加 #歌曲id，例如 https://你的網址/#amazing-grace

【調整對不上的時候】
影片和譜差一點點：改畫面上的「起始位置(秒)」，例如 0.5、-0.3。找到對的數字後，記到 songs.json 的 offset。

【注意】
放上網站的 GP 檔，別人只要知道檔案網址就能下載。若是付費內容，需要再加上登入／權限控管，之後可以再做。

【節拍器與單獨聽譜】
・「節拍器」勾選後，可選 4分音符或 8分音符，每小節第一拍的聲音較高。音量可調。
・「播放來源」選「譜面鼓聲（影片靜音）」：不用影片，直接用譜上的鼓聲播放，速度、循環、節拍器都能用。
  選回「影片聲音」就恢復用 YouTube 影片的聲音。
・節拍器聲音若和影片有一點點落差，這是正常的網頁延遲；以「譜面鼓聲」模式使用時比較穩。
