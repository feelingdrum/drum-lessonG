# 鼓譜練習器（Drum Practice Player）— 調整紀錄

- **調整日期**：2026-11-26
- **版本標記**：介面 v7（基於 alphaTab 1.9.0）

## 檔案清單

- `index.html`：主程式（已套用本次 7 項功能與 UI/UX 優化）
- `CHANGELOG.md`：自 v1 至今完整功能更新日誌
- `README.md`：本次功能調整紀錄與使用說明

## 本次調整項目（v7）

1. **自動換行提早一行**
   - 修改 `aheadScroll()` 觸發列為 `Math.max(a, b - 2)`，行末觸發比例調整為 `0.35`，使自動捲動比原本提早一行執行。
2. **手機觸控選取循環範圍**
   - 加入「📱 觸控框選」開關，透過 Pointer Events 對應譜面小節座標並設定 `touch-action: none`，在手機上可直接手指拖曳框選循環區間而不誤觸畫面捲動。
   - 同步提供「設起點 A」與「設終點 B」按鈕，可透過點擊小節快速定義循環起訖範圍。
3. **預備拍（Count-In）功能**
   - 在進階面板加入「預備拍（1小節）」開關與 `startWithCountIn()`，按下播放時依目前拍號與播放速度發出節拍器重音/拍點並顯示倒數畫面，完成後自動開始播放。
4. **收合細節功能與播放時精簡介面**
   - 將非核心設定收納至預設收合的 `#advPanel`（進階與練習工具）。
   - 播放中自動套用 `body.is-playing`，僅顯示「播放/暫停、停止、速度、節拍器」四項核心操作，最大化影片與鼓譜版面。
5. **UI/UX 優化**
   - 建立獨立 `#coreBar` 核心控制卡片、新增 `#loopBadge` 循環區間狀態徽章與 `#countInOverlay` 倒數提示層，改善操作層級與辨識度。

## 使用與維護規範

- **每次修改必更新紀錄**：後續每次調整功能時，請同步更新 `README.md` 與 `CHANGELOG.md` 留存版本紀錄。
- **執行環境**：需透過網站伺服器（如 Cloudflare Pages 或本機 HTTP Server）開啟，以正常讀取 `songs.json`、`alphaTab.min.js` 與 `drums.sf2`。
